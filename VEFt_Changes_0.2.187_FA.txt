VEFt نسخه 0.2.187 — بزرگ‌کردن محدوده واقعی تصویر پلیر

- محدودیت ثابت ۱۶۰dp از ارتفاع تصویر پلیر حذف شد؛ ارتفاع واقعی تصویر اکنون تا ارتفاع قابل‌استفاده ردیف پلیر افزایش می‌یابد.
- تصویر با حفظ نسبت ابعاد اصلی و بدون کشیدگی یا فشردگی در فضای پلیر جاگذاری می‌شود.
- وقتی نسبت ابعاد ویدیو اجازه پرکردن کامل ارتفاع را ندهد، تصویر واقعی در ردیف پلیر به‌صورت عمودی وسط‌چین می‌شود تا فاصله اضافی در یک سمت جمع نشود.
- لایه‌های ویدیو، پیش‌نمایش رنگ، برش و ابزارهای جای‌گذاری همچنان از اندازه و محدوده یکسان استفاده می‌کنند.
- تنظیمات GitHub Actions و سایر قابلیت‌های پروژه تغییر نکردند.

موارد قطعیِ تکمیل‌نشده و مراحل بعدی
- [قطعی] اجرای Build در GitHub Actions و تولید APK نسخه ۰.۲.۱۸۷ باید تأیید شود.
- [قطعی] اندازه و جای‌گیری تصویر واقعی پلیر با ویدیوهای افقی و عمودی روی دستگاه بررسی شود.
- [قطعی] هماهنگی دستگیره‌های Crop و ابزارهای جای‌گذاری با محدوده تصویر بزرگ‌شده روی دستگاه بررسی شود.
